# Genshin Impact Tracker

Sube estos archivos a un repositorio de GitHub Pages.

- index.html: interfaz
- styles.css: diseño responsive
- app.js: lógica, cuota, pity, historial, cierre de día, undo y backups
- manifest.json: PWA
- service-worker.js: funcionamiento offline/caché

En GitHub: Settings > Pages > Deploy from branch > main > /root.

Los datos se guardan en localStorage del navegador. Usa Exportar para respaldarlos.
